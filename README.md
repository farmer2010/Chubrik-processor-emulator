# Эмулятор [процессора](https://github.com/chubrik/LogicArrows/tree/main/ru/computer-v2) в игре [Logic Arrows](https://logic-arrows.io/)

Бета - версия эмулятора

Для запуска необходима библиотека pygame

Для смены запускаемой программы надо в инициализации класса `Emulator` файла `emulator.py` заменить адрес в строке с загрузкой программы

Для смены скорости надо изменить переменную `self.speed`. Она обозначает, сколько шагов будет пропущено до отрисовки

## Управление:

`F1` - старт/пауза

`F2` - перезапуск программы

`F3` - 1 шаг программы

## Планируется:

1. Диалоговое окно для выбора программы

2. Консоль с ошибками компиляции

3. Настройка скорости в шагах в секунду

4. Интерфейс

5. Режим просмотра памяти

6. Изменяемые размеры консоли

7. Поддержка разрешений монитора кроме 1920*1080
