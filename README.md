# Эмулятор [процессора](https://github.com/chubrik/LogicArrows/tree/main/ru/computer-v2) в игре [Logic Arrows](https://logic-arrows.io/)

Бета - версия эмулятора

Для запуска необходима библиотека pygame

Для смены запускаемой программы надо в инициализации класса `Emulator` файла `emulator.py` заменить адрес в строке с загрузкой программы

Для смены скорости надо изменить переменную `self.speed`. Она обозначает, сколько шагов будет пропущено до отрисовки

## Управление:

`F1` - старт/пауза

`F2` - перезапуск программы

`F3` - 1 шаг программы

`BACKSPACE` - 1 шаг программы, если текущая команда - `0x02`(suspend. Приостанавливает работу программы до нажатия `BACKSPACE`)

## Планируется:

1. Диалоговое окно для выбора программы

2. Консоль с ошибками компиляции

3. Настройка скорости в шагах в секунду

4. Интерфейс

5. Режим просмотра памяти

6. Изменяемые размеры консоли

7. Поддержка разрешений монитора кроме 1920*1080

# Скрипт для преобразования картинки в ассемблерный код

`image_to_asm.py`

Полезен для создания заставок

Для запуска необходимы библиотеки: pygame, pyperclip

При запуске скрипт спрашивает путь до целевого файла с указанием расширения. После указания файла копирует в буфер обмена и выводит в консоль результат работы

Размер изображения должен быть не менее 16*16 пикселей

Поддерживает как цвета дисплея эмулятора (#ff0000 - красный, #4c80ff - синий, #a54080 - фиолетовый), так и стандартные цвета(#ff0000 - красный, #0000ff - синий, #ff00ff - фиолетовый). Может поддерживать промежуточные, не проверял
