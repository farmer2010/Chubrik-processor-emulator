# Эмулятор [процессора](https://github.com/chubrik/LogicArrows/tree/main/ru/computer-v2) в игре [Logic Arrows](https://logic-arrows.io/)

Для запуска необходимы библиотеки: `pygame`, `crossfiledialog`

## Управление:

`ESCAPE` - Перейти в главное меню

`F1` - Старт/пауза

`F2` - Перезапуск программы

`F3` - 1 шаг программы

`F4` - 1 шаг программы, если текущая команда - `0x02`(breakpoint. Приостанавливает работу программы до нажатия `F4`)

`F5` - Перейти в консоль

`F6` - Перейти в режим просмотра памяти

## Планируется:

1. Поддержка разрешений монитора кроме 1920*1080

2. Сохранение/загрузка состояния эмулятора

# Скрипт для преобразования картинки в ассемблерный код

`image_to_asm.py`

Полезен для создания заставок

Для запуска необходимы библиотеки: pygame, pyperclip

При запуске скрипт спрашивает путь до целевого файла с указанием расширения. После указания файла копирует в буфер обмена и выводит в консоль результат работы

Размер изображения должен быть не менее 16*16 пикселей

Поддерживает как цвета дисплея эмулятора (#ff0000 - красный, #4c80ff - синий, #a54080 - фиолетовый), так и стандартные цвета(#ff0000 - красный, #0000ff - синий, #ff00ff - фиолетовый). Может поддерживать промежуточные, не проверял
